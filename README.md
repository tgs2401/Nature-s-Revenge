# Nature's Revenge

## Objective

a game i made for the evergreen hackathon!!
<br>
you play as Skep (a super awesome robot i came up with a few years or so ago that just so happened to kinda fit the theme "nature fights back")
<br> 
and you have to get to the door at the end of each level to win

## Controls

a / left arrow: move left
<br>
d / right arrow: move right
<br>
z / space: jump
<br>
x / shift: run
